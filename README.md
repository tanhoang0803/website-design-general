# Website Design General

A pixel-perfect website recreation project built with **Tailwind CSS**. This project replicates the **LeftClick AI** landing page — a dark-themed, modern agency website — from a reference design screenshot.

## Tech Stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Google Fonts (Inter Tight)

## Project Structure

```
.
├── index.html       # Main page (all styles and content inline)
├── .gitignore
└── README.md
```

## Features

- Responsive, mobile-first layout
- Dark theme with custom color palette
- Fixed navigation with blur backdrop
- Case studies, services, pricing, and FAQ sections
- Smooth hover effects and transitions

## Getting Started

No build step needed. Just open `index.html` in your browser.

```bash
open index.html
```

## Workflow

This project follows a screenshot-driven design workflow:

1. Generate HTML from a reference image
2. Screenshot the rendered page
3. Compare against the reference and fix mismatches
4. Repeat until pixel-perfect
